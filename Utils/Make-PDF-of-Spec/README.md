# YINI Spec MD to PDF

This Node.js project makes a PDF-file from the YINI-Specification.md file.

### Uses
- markdown-it (Markdown to HTML)
- puppeteer (HTML to PDF)
- github-markdown-css (for styling)

## Usage

### Installation
Run in your terminal:
```bash 
npm install
```

### Run the Example
```bash
npm start
```
